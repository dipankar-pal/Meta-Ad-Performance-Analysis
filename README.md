🎯 Meta Ad Performance Analysis Dashboard

A complete Power BI + Figma analytics project designed to analyze Meta ad performance across impressions, engagement, clicks, purchases, demographics, and ad types.

📌 Project Overview

This dashboard provides a 360° view of Meta advertising performance. It is built to help marketers and businesses understand:

Which campaigns generate the highest impressions

Hourly & weekly engagement trends

Top-performing ad types (Image, Video, Carousel, Story)

Country-wise and demographic insights

Budget usage and cost efficiency

Key metrics like CTR, Conversion Rate, Engagement Rate

🛠️ Tools & Technologies

Power BI – Dashboard development, DAX, Data Modeling

Power Query – Data cleaning & transformation

Figma – UI/UX layout design

Bookmarks & Parameters – Dynamic navigation

Star Schema Modeling – Fact & dimension tables
